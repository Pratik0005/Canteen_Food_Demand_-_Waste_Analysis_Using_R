# Canteen Food Demand & Waste Analysis Using R

Interactive R Shiny dashboard.

## Run
1. Install R and RStudio.
2. Install packages (once):
   `install.packages(c("shiny","bslib","dplyr","tidyr","plotly","DT","readr","scales"))`
3. Keep `app.R` and `canteen_food_demand_waste_dataset.csv` in the same folder.
4. Open `app.R` in RStudio and click **Run App**, or run `shiny::runApp("canteen_dashboard")`.

## Tabs
Overview, Waste Analysis, Demand Patterns, What-If Planner, Insights, Data.
